# AGENTS.md

ここは運用者固有の非公開情報を管理する private ops リポジトリです。構成や運用方法の基本は [README.md](README.md) と `mc-remote-stack` のガイドを参照してください。

- **秘密実値・生ログを Git に残さない**: トークン、パスワード、秘密鍵、バックアップ実体、未マスクのログやダンプは commit しません。
- **台帳より実機を確かめる**: `inventory.md` は過去時点の記録である場合があります。変更作業の前は SSH 等で実機の現在状態を直接確認し、作業後に台帳と `deployments/` を更新してください。
- **主体的に改善し、汎用知見は還元する**: 運用しやすくなる構成整理やメモの工夫は自由に進めて構いません。他環境でも役立つ手順やスクリプトの改善が見つかれば、`mc-remote-stack` 側へ還元してください。
